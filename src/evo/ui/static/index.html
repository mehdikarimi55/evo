    PUBLIC TRUST · v0.8
    
                
    Independent trust authority
    
                
    
                  Publish an Ed25519 evidence attestation, verify an independently signed reviewer decision, and evaluate the immutable promotion policy.

    CONTROLLED RELEASE · v0.9
    
                
    Reproducible local promotion
    
                
    
                  Preserve the exact sandbox-verified patch, consume one signed authorization, and support exact-state rollback from the CLI.
                
    
              
    
              
    
              
    
                Apply and rollback are CLI-only and require exact confirmation phrases. EVO never commits, pushes, merges, or deploys the promoted worktree.

    PRODUCTION HANDOFF · v1.0
    
                
    Signed external deployment handoff
    
                
    
                  Bind a committed release to signed stage, health, production, and rollback intents, then verify receipts from an independent operator.
                
    
              
    
              
    
              
    
                This panel is read-only. EVO holds no cloud credentials and performs no network deployment; an independent operator executes every external change.
